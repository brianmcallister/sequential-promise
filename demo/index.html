sequential-promise

Run promises that depend on each other, one after another. Each request waits for the one before it to settle, and gets every earlier result. 

npm install @brianmcallister/sequential-promise

Four requests that depend on each other

You can't load someone's orders before you know who they are. Make a request fail, then run it again to see how each approach reacts.

    Do you still need this library?

    Probably not. When this was written in 2019, Promise.allSettled hadn't shipped yet and running promise-returning functions in order meant reaching for reduce. Today a for...of loop with await does the same job in three lines, as the examples above show.

    If your requests don't need earlier results, Array.fromAsync (ES2024) runs them in order and rejects on the first failure, just like sequential: 

    const results = await Array.fromAsync(requests, (request) => request());

    The library still works, and its TypeScript types are handy, but a loop you can read at a glance is usually the better choice.
